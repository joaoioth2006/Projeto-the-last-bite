# The Last Bite

O **The Last Bite** é um projeto acadêmico de desenvolvimento front-end que consiste em um site para um restaurante temático de terror. A proposta é combinar uma identidade visual sombria com uma experiência de navegação intuitiva e uma apresentação atrativa dos produtos e do ambiente do restaurante.

## Objetivo

Desenvolver um site para um restaurante fictício, aplicando conhecimentos de desenvolvimento front-end, estruturação de páginas, estilização, responsividade e interatividade com JavaScript.

## Funcionalidades

- **Home:** página inicial com apresentação do restaurante e destaque para seus produtos.
- **Cardápio:** apresentação dos produtos oferecidos pelo restaurante.
- **Sobre nós:** apresentação da proposta e da identidade do estabelecimento.
- **Galeria:** exposição de imagens dos produtos e do ambiente, com recurso de ampliação de imagens.
- **Contato:** página com informações de contato.
- **Login:** interface de entrada do usuário.
- **Menu lateral:** navegação entre as páginas do site.
- **Layout responsivo:** adaptação da interface para diferentes tamanhos de tela.

## Tecnologias utilizadas

- **HTML5:** estruturação do conteúdo e utilização de elementos semânticos.
- **CSS3:** estilização, organização dos layouts, efeitos visuais e responsividade.
- **JavaScript:** implementação de funcionalidades interativas.
- **Bootstrap Icons:** biblioteca de ícones utilizada na interface.
- **Git:** controle de versão do projeto.
- **GitHub:** hospedagem do repositório e gerenciamento do código-fonte.

## Como usar

1. Acesse a página inicial do site.
2. Utilize o menu lateral para navegar entre as páginas disponíveis.
3. Acesse o cardápio para conhecer os produtos apresentados pelo restaurante.
4. Visite a galeria para visualizar imagens dos pratos e do ambiente.
5. Clique nas imagens da galeria para ampliá-las, caso o recurso esteja disponível.
6. Acesse a página Sobre nós para conhecer a proposta do estabelecimento.
7. Consulte a página Contato para visualizar as informações disponibilizadas.
8. Acesse a página Login para visualizar a interface de entrada do usuário.

## Como executar o projeto

### Pré-requisitos

- Navegador atualizado.
- Git instalado.
- Visual Studio Code (opcional).
- Extensão Live Server no Visual Studio Code (opcional).

### Instalação

1. Clone o repositório:

   ```bash
   git clone https://github.com/joaoioth2006/Projeto-the-last-bite.git
   ```

2. Entre na pasta do projeto:

   ```bash
   cd Projeto-the-last-bite
   ```

3. Abra a pasta no Visual Studio Code:

   ```bash
   code .
   ```

4. Abra o arquivo `home.html` diretamente no navegador ou utilize a extensão Live Server para executar o site localmente.

## Identidade visual

O projeto apresenta uma identidade visual inspirada no terror, utilizando tons escuros como base, detalhes em vermelho e textos em tons de bege.

A composição visual busca transmitir uma atmosfera temática e diferenciada, mantendo a organização dos elementos, a legibilidade dos textos e a facilidade de navegação.
